VASP run index for soft-magnet ML cross-validation
============================================================

This directory contains POSCAR files and README notes for all
non-SQS DFT runs in the plan. Cells covered:
  - bcc Fe (benchmark)
  - B2 FeCo
  - L1_2 Fe3Co (Fe-rich analog)
  - L1_2 FeCo3 (Co-rich analog)

Solid-solution cells (random Fe-Co-Ni-Mn-Al-Si compositions)
are NOT generated here. Those require SQS and are handled by
a separate script in the next phase.
